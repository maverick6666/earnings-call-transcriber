# 🎧 어닝콜 받아쓰기 — 경계 손실 · 오인식을 숫자로 줄이기 (작업 중)

녹음을 청크로 잘라 받아 적으면 **잘린 자리의 낱말이 사라지거나 틀린다.** 이 저장소는 그 문제를 줄이는 방법들을
**같은 평가 틀에서 숫자로 비교**하고, 이긴 방법으로 어닝콜 받아쓰기 파이프라인을 만드는 것이 목표다.

> 지금 단계: **평가 틀 완성 · 가짜 모델로 작동 확인.** 진짜 모델(faster-whisper) · 평가 자료(Earnings-21 · Zeroth-Korean)는
> 내려받기 허락을 기다리는 중이라, 아래 숫자는 아직 실제 성능이 아니다.

## 비교할 방식

| 이름 | 방식 | 근거 |
|---|---|---|
| B0 | 60초 고정 청크, 겹침 없음(지금 wspr) | 기준선 |
| B1 | 모델 자체의 긴 오디오 처리(30초 창, 앞 문장 이어 받기) | faster-whisper 기본 |
| O1 | **겹쳐 자르기**: 1+2, 2+3 … 절반씩 겹친 창, 겹친 구간 가운데에서 잇기 | 사용자 아이디어 · HF 청크 stride |
| O2 | O1 + **겹친 구간 투표**: 두 번 같게 나온 낱말은 확정, 다르면 단어 확률이 높은 쪽 | Whisper-Streaming LocalAgreement(2023) · ROVER(1997) |
| V1 | 무음에서 자르고 30초 안으로 이어 붙임, 긴 무음은 받아 적지 않음 | WhisperX(Interspeech 2023) |
| V2 | V1 + 양옆 1초 겹침 | — |
| +P | 회사별 용어집 hotwords(공시 · 사업보고서에서 고유명사 뽑기) | `initial_prompt` 는 첫 창만, hotwords 는 창마다 |
| +L | LLM 교정 + **지어낸 문장 거르기**(정렬로 덧붙인 말 검사) | HyPoradise(NeurIPS 2023) · Careless Whisper(FAccT 2024) |

## 재는 것

| 숫자 | 뜻 |
|---|---|
| WER / CER | 전체 오류율(영어 낱말 / 한국어 글자) |
| **경계 오류율** | 청크를 자른 시각 ±2초 안 오류만 — 이 문제를 직접 재는 숫자 |
| 고유명사 · 숫자 오류율 | Earnings-21 꼬리표(ORG · PRODUCT · CARDINAL · MONEY …) 낱말 중 틀린 비율 — 어닝콜에서 가장 비싼 오류 |
| 지어낸 문장 | 정답에 없는 낱말이 4개 넘게 이어진 덩어리(시간당) |
| 받아 적은 소리 | 녹음 길이 대비 몇 배를 모델에 넣었나(겹치면 계산이 는다) |

## 지키는 규칙

1. 녹음의 모든 시간 구간은 결과에 **정확히 한 번** 반영된다 — 청크 계획마다 검사(`chunking.check_partition`).
2. 결과의 모든 낱말은 녹음 시각을 가진다. 교정된 낱말은 원래 글을 `original` 에 남긴다.
3. 교정은 정렬 검사를 통과해야 한다. 원래 받아쓰기에 없는 3낱말 넘는 덧붙임은 버린다(`correction.apply_correction`).
4. 같은 녹음 + 같은 설정 → 같은 결과. 설정 · 모델 버전 · 결과 해시를 실행 기록에 남긴다.
5. 중간에 멈췄다 다시 돌리면 끝난 청크는 다시 받아 적지 않는다(저장본 열쇠 = 설정 해시 + 녹음 + 청크 구간).

## 가짜 모델로 본 작동 원리

알려진 실패 모양을 흉내 내는 가짜 모델로 각 방식을 돌렸다([보고서](reports/simulation.md)). **진짜 성능이 아니다.**

- B0 는 자른 곳 ±2초 안 오류가 그 밖의 다섯 배(30.4% vs 6.1%) — 계산기가 경계 손실을 잡는다.
- O1(겹쳐 자르기)은 가정과 상관없이 경계 손실을 없앤다(6.4% ≈ 6.1%). 대신 계산이 두 배.
- O2(투표)는 단어 확률이 맞고 틀림을 알려 줄 때만 가장 좋다(3.0%). 그렇지 않으면 O1 보다 나쁘다(8.3%) → 실제 모델의 확률부터 재야 한다.
- V1 · V2(5초 넘는 무음 건너뛰기)는 대기음에서 지어낸 문장을 줄인다(시간당 15 → 4~10). V2 는 네 가지 가정 모두에서 고르게 좋다(5.5~5.8%, 계산 1.05배).

## 구조

```text
src/callscribe/
  words.py       낱말 = 글 + 시각 (+ 확률 · 청크 · 투표 일치 · 교정 전 글)
  normalize.py   영어 낱말 / 한국어 글자 정규화
  align.py       편집 거리 정렬(긴 글은 띠 정렬, 경로가 띠 가장자리에 닿으면 넓혀 다시)
  metrics.py     WER · 경계 오류율 · 고유명사/숫자 · 지어낸 문장
  chunking.py    B0 · B1 · O1/O2 · V1/V2 청크 계획 + '정확히 한 번 덮기' 검사
  merge.py       own 구간으로 잇기 · 겹친 구간 투표 · 이음매 중복 제거
  runner.py      실행 · 저장본으로 이어 하기 · 실행 기록
  correction.py  +L 교정 검사
  glossary.py    +P 용어집 · hotwords · 용어 재현율
  datasets.py    Earnings-21(.nlp · wer_tag.json) · Zeroth-Korean 읽기, 긴 한국어 오디오 만들기
  backends.py    faster-whisper 연결(설치 · 모델 내려받기 뒤)
  simulate.py    가짜 통화 · 가짜 모델
scripts/simulate_compare.py   가짜 모델로 방식 비교 → reports/simulation_summary.json
tests/                        정렬 · 점수 · 청크 · 잇기 · 실행 · 자료 읽기 · 교정 · 용어집 (41개)
```

## 실행

```bash
pip install -e ".[dev]"
python -m pytest
PYTHONPATH=src python scripts/simulate_compare.py
pip install -e ".[asr]"   # 진짜 모델(faster-whisper) — 모델 파일은 처음 실행 때 내려받음
```

평가 자료 · 녹음 · 모델은 저장소에 넣지 않는다(.gitignore).
